## 🚀 كيفية تفعيل استضافة GitHub Pages بنقرة واحدة:
1. ادخل إلى صفحة مستودعك على جيت هاب: [https://github.com/mahmoudomran324/Bekalte-stor](https://github.com/mahmoudomran324/Bekalte-stor)
2. انقر على **Settings** (الإعدادات) في أعلى المستودع.
3. من القائمة الجانبية اختر **Pages**.
4. تحت قسم **Build and deployment**، في خانة **Source**، اختر:
   **`GitHub Actions`**
5. سيقوم جيت هاب تلقائياً ببناء المشروع ونشره على الرابط:  
   `https://mahmoudomran324.github.io/Bekalte-stor/` دون أي خطأ 404!

## ✨ المميزات الرئيسية:
- **المحادثات الجماعية**: غرف مصنفة مع إظهار عدد المتواجدين في كل غرفة لحظياً.
- **المحادثات الخاصة**: محادثات 1 على 1 مشفرة وسريعة مع تنبيهات صوتية.
- **مشاركة ورفع الصور**: إمكانية رفع الصور ومعاينتها وتكبيرها عبر عارض الصور المدمج.
- **تسجيل الدخول والخروج**: دخول سريع بالاسم المستعار أو عبر Gmail، مع نافذة تأكيد الخروج.
- **أداة فلترة الكلمات المحظورة**: حجب الألفاظ غير اللائقة تلقائياً بـ `***` أو منع إرسالها.
- **لوحة تحكم المشرفين**: إدارة الأعضاء، الحظر، كتم الصوت، إضافة وتعديل غرف المحادثة وتدقيق الصور.
